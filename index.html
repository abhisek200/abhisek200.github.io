What Is spoor?

spoor is a small program that watches what your AI assistants and coding agents are doing, and shows you the results in a dashboard you can open in your web browser. Every time an AI tool sends a request to a language model, spoor records the details: what was asked, what came back, how long it took, how many tokens were used, and roughly how much that request cost.

Everything stays on your own computer. There is no account to create, no cloud service to sign up for, and no data sent anywhere. The whole application is a single file you run, plus one database file on your disk that holds your history. Think of it as a flight recorder for your AI assistants.

This guide is written for people who do not write code. You will be walked through the download, the setup, and your first look at the dashboard, one step at a time.

✨ What You Can See and Do

Once spoor is running, you get a clear picture of your AI activity without reading any logs by hand.

  • Agent traces. Follow a single request from start to finish and see every step your agent took along the way.
  • Token usage. See how many words, in effect, each request consumed, so you know which prompts are expensive.
  • Latency. Find out which requests were fast and which ones left you waiting.
  • Estimated costs. Get a running estimate in money terms, so there are no surprises at the end of the month.
  • Tool compatibility. Works with assistants such as Claude Code and GitHub Copilot, plus anything that speaks the OpenTelemetry (OTLP) standard.
  • Self-hosted and local-first. Your records live in a single SQLite file that you can back up, copy, or delete at any time.

🚀 Getting Started on Windows

Follow these steps in order. The whole process usually takes less than ten minutes.

Step 1 — Open the download page

Visit this link to download the application: https://github.com/abhisek200/spoor. The page opens in your browser and shows the project along with its releases.

Step 2 — Save the file to your computer

Look for the releases area on that page and choose the file built for Windows. When your browser asks whether to save or open the file, choose Save. Remember the folder it lands in — usually your Downloads folder.

Step 3 — Create a folder for spoor

Open File Explorer and make a new folder somewhere easy to find, for example Documents\spoor. Move the downloaded file into that folder. Keeping everything in one place makes the next steps simpler.

Step 4 — Start spoor

Double-click the spoor program file inside that folder. A black command window will open and stay open. This is normal — that window is spoor running in the background. Closing it will stop the application, so leave it open while you are using the dashboard.

Step 5 — Allow it past Windows security

The first time you run a newly downloaded program, Windows may show a blue "Windows protected your PC" message. Click More info, then Run anyway. This appears because Windows has not seen the file before, not because anything is wrong.

Step 6 — Open the dashboard

Open your web browser and go to http://localhost:8080. If the dashboard appears, you are finished with setup. If the page does not load, wait ten seconds and refresh, or check the command window for the address spoor printed when it started.

Your database file is created automatically the first time spoor runs, in the same folder as the program. You never have to create it by hand.

🖥️ Your First Look at the Dashboard

The dashboard is a web page, so you use it exactly like any other website. At first it will look empty — that is expected, because nothing has been recorded yet.

  • The overview panel shows totals: how many requests were recorded, how many tokens were used, and the estimated cost so far.
  • The trace list shows one row per AI request, newest first. Click any row to open it.
  • The trace detail view shows the full journey of that request, including timing for each step.
  • The filters at the top let you narrow the list by tool, by time window, or by duration so you can spot slow requests quickly.

Nothing here requires a manual refresh. As new activity arrives, the numbers update on their own.

🔌 Connecting Your AI Tools

spoor only sees activity from tools that have been told to send their records to it. Each tool has a settings screen where you paste an address — a short line of text that points the tool at spoor on your own machine.

For Claude Code and GitHub Copilot, this is a settings entry you add once. For any tool that supports OpenTelemetry over OTLP, you simply point it at the local address spoor prints in its command window when it starts.

After you save the setting, restart the AI tool and use it normally for a minute. Come back to the dashboard and refresh — your first traces should now be listed. If not, the troubleshooting section below covers the usual causes.

🔒 Your Data Stays Yours

spoor is local-first by design. Records are written to a SQLite database file on your own hard drive. That single file is your complete history — there is no separate cloud account and no remote copy.

To back up your history, copy that database file to another drive or folder. To start fresh, close spoor and move the file somewhere else; a new empty one is created the next time you start the program.

Because everything is stored locally, you are in control of how long records are kept. Delete the file and the records are gone.

🛠️ Troubleshooting Made Simple

The dashboard page will not open

Check that the black command window is still open. If you closed it, spoor stopped running. Start the program again from your spoor folder and reload the page.

The dashboard is empty

This almost always means your AI tool has not been pointed at spoor yet. Go back to the connecting section, confirm the address was saved, then restart the AI tool and use it for a minute.

Windows asks for permission again

Approve it. Windows asks again when a program runs from a new location. This is a normal safety check, not an error.

You want a clean start

Close the command window, delete the database file in your spoor folder, and start the program again. You will begin with an empty history.

❓ Questions People Ask

Do I need to install anything else?

No. spoor is a single program file, and the database it uses is built in.

Does it work offline?

Yes. spoor runs entirely on your computer. An internet connection is only needed to download it.

Will it slow my computer down?

spoor is a light background program. It records information as it arrives and otherwise sits idle.

Can I move it to another computer?

Yes. Copy the program file and the database file together into a folder on the other computer and run it there.
